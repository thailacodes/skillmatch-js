# SkillMatch JS

## Objetivo

O projeto **SkillMatch JS** simula um sistema de compatibilidade entre candidatos e vagas de emprego.
Ele analisa habilidades, calcula percentuais de compatibilidade e gera recomendações de estudo para melhorar o perfil do candidato.

---

## Como executar

1. Abra o navegador Google Chrome.
2. Pressione **F12** para abrir o Console.
3. Copie todo o conteúdo do arquivo `skillmatch.js`.
4. Cole no Console e pressione **Enter**.
5. Os resultados da análise aparecerão diretamente no Console.
